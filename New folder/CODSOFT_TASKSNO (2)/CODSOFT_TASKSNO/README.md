# CodSoft C++ Programming Internship Projects

Welcome to my repository for the **CodSoft C++ Programming Internship**. This repository contains clean, modular, and tested C++ implementations for three completed internship tasks.

## Project Overview

| Task # | Project Name | Description | Source File |
| --- | --- | --- | --- |
| **01** | **Number Guessing Game** | Random number game that gives high/low feedback until the user guesses correctly. | `Task1_Number_Guessing_Game/main.cpp` |
| **02** | **Simple Calculator** | Interactive calculator supporting addition, subtraction, multiplication, and division. | `Task2_Simple_Calculator/main.cpp` |
| **04** | **To-Do List Manager** | Console task manager supporting add, view, complete, remove, and clear operations. | `Task4_Todo_List/main.cpp` |

## How to Run the Projects

### What You Need Before Running

- A C++ compiler or online C++ compiler
- The C++ source-code files

You can use Code::Blocks, Dev-C++, Visual Studio Code, OnlineGDB, Programiz, or another C++ compiler.

### Clone the repository

```cpp
git clone https://github.com/YOUR-GITHUB-USERNAME/CODSOFT_TASKSNO.git
cd CODSOFT_TASKSNO
```

Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.

### Task 1: Number Guessing Game

```bash
g++ -std=c++17 Task1_Number_Guessing_Game/main.cpp -o guessing_game
./guessing_game
```

The computer selects a number between 1 and 100. The program tells the player whether each guess is too high or too low.

### Task 2: Simple Calculator

```bash
g++ -std=c++17 Task2_Simple_Calculator/main.cpp -o calculator
./calculator
```

The calculator performs addition, subtraction, multiplication, and division. It also validates input and prevents division by zero.

### Task 4: To-Do List Manager

```bash
g++ -std=c++17 Task4_Todo_List/main.cpp -o todo_list
./todo_list
```

The to-do list allows users to add tasks, view pending or completed tasks, mark tasks as completed, remove individual tasks, and clear the list.
